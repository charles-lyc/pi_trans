# PiTrans

[English](README.md) | **简体中文**

运行在树莓派上的实时语音翻译。插上 USB 麦克风，说中文或英文，原文和译文会在网页上实时滚动显示，同一网络里的人用手机或电脑打开网页就能看。

## 使用场景

- **技术分享、会议演讲**（如 KiCon Asia）：讲者说中文，听众在手机上看英文字幕；反过来也可以。
- **Meetup、讲座、培训**：投到投影或大屏上，做双语字幕。
- **跨语言交流**：留下双方说话内容的文字记录。

## 功能特色

- **两种模式**：本地语音识别加云端翻译（成本低，断网时识别照常工作）；或者云端同传，边说边出译文。
- **灵活的翻译**：中译英、英译中或自动识别方向。共 6 个翻译引擎，一个失败时自动切换到下一个。
- **专业术语表**：211 条术语，覆盖硬件、KiCad / PCB、嵌入式、网络和 AI。
- **防提示词注入**：说的话即使像一条指令，也只会被翻译，不会被执行。
- **听众无需安装**：任何浏览器打开网页即可。多台设备之间设置同步，网页上有实时波形、状态灯和各引擎统计。
- **像家电一样用**：开机自启、崩溃自动重启，麦克风和云端断开后自动重连。不同场地的 Wi-Fi 可以提前存好。

## 工作原理

```
USB 麦克风 ─► arecord（16 kHz 单声道）
               ├─ 模式 A：Silero VAD ─► SenseVoice（树莓派本地）─► 云端翻译引擎
               └─ 模式 B：音频流 ─► Qwen 同传（识别 + 翻译）
                                   │
                    FastAPI + WebSocket ─► 浏览器（可多台同时）
```

| 部分 | 选型 |
| --- | --- |
| 硬件 | 树莓派 4B（2 GB）+ USB 麦克风 |
| 语音识别 | sherpa-onnx，SenseVoice-Small（int8）+ Silero VAD，在树莓派 CPU 上运行 |
| 翻译 | Qwen 同传、Qwen-MT、DeepSeek、GLM-4-Flash、Google、MyMemory |
| 服务 | Python、FastAPI、WebSocket |
| 网页 | 单个 HTML 文件，不依赖任何框架 |
| 系统 | systemd 服务、NetworkManager |

在树莓派上，服务占用约 510 MB 内存，空闲时约占 5% 单核。识别耗时约为音频时长的 0.3 倍，每句说完后 1～2 秒出译文。
